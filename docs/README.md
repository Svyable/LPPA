# Princess Puppy Adventures Public Site

This directory is the static pre-launch website for **Princess Puppy Adventures**.

## Deployment

The site is deployed with `.github/workflows/pages.yml`.

One-time repository setup is still required:

**Settings → Pages → Build and deployment → Source → GitHub Actions**

After that setting is enabled, re-run the Pages workflow or commit a change under `docs/`.

Expected URL:

https://svyable.github.io/LPPA/

## Pre-launch content rules

- Keep the status as **Coming soon** until the Amazon listing is genuinely live.
- Do not add an Amazon purchase button until the real detail-page URL exists.
- Do not use candidate Leia art as final public branding without deliberate approval.
- Keep Chelsea Nash credited as author and Sven Hardy Benson credited as illustrator.
- Keep the public series/brand name **Princess Puppy Adventures**.
- Avoid exposing production-only notes, KDP identifiers, or internal QA material on the public site.

## Future launch update

When the physical proof is approved and the Amazon listing is live, update this site with:
- approved cover art;
- a verified purchase link;
- final product description;
- a few approved interior previews;
- series/newsletter or social links if available.
